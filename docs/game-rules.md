# Game Rules: Classic Manhunt

## 1. Objective
- **Runners**: Evade capture by staying inside the designated Play Zone until the match timer runs out. Runners win as a team if at least one runner remains free at $00:00$.
- **Chasers**: Track down and successfully tag/catch every runner before the timer expires. Chasers win if all runners are eliminated before time runs out.

---

## 2. Match Sequence
1. **Lobby & Setup**:
   - Host chooses duration (default 15 minutes) and draws a circular Play Zone in a familiar outdoor park or campus.
   - Players join via 6-character code. Host assigns teams: Runners and Chasers.
   - Host sets the Scatter / Head Start duration (e.g. 2 minutes for runners, or staggered per runner).
2. **Head Start / Scatter Phase**:
   - When the host starts the match, runners are immediately released into the field to disperse.
   - Chasers are physically held at the starting point. The chaser interface displays a large countdown timer until release.
3. **The Active Chase**:
   - Once chasers are released, the main match countdown commences.
   - Chasers receive runner location pings at the configured interval (e.g., every 45-60 seconds).
   - Runners do not see chasers on their map, but receive team radio audio and boundary warning alerts.
4. **Catch Execution**:
   - When a chaser gets close (<25m), they tap **"Tag Runner"**.
   - The runner receives an on-screen prompt: **"Chaser [Name] claims a catch. Confirm or Dispute?"**
   - Alternatively, the runner shares their dynamic 4-digit catch code with the chaser to enter.
   - If disputed, the Referee or Host reviews the proximity and can override.
   - Confirmed caught runners become eliminated spectators or cheerleaders.
5. **Boundary Rules**:
   - Crossing the boundary circle triggers a warning. A 30-second countdown gives the runner time to return. Failing to return results in a forced location reveal to chasers.
6. **Safety Rules**:
   - Real-world safety always overrides the game. Never cross traffic or private property unsafely.
   - Either Host or Referee can press **"Safety Pause"** at any moment to freeze the game immediately.
